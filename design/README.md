# Design direction (v2)

Built from analysis of two reference marketplaces (screens supplied by the owner):
- neutrals: near-black `#0E0E10`/`#0E111C`, surfaces `#1E1F28`
- one accent colour per brand; content-first pages without a marketing hero
- image-led cards, trust blocks *below* the storefront, pastel tint cards for guarantees

Ours: neutrals `#0E0F14 / #161822 / #1E212E`, accent coral `#FF6B4A` (not blue, not amber),
green reserved for "in stock / verified", rarity colours only on collections.
Type: Onest (UI) + Barlow Condensed (game tiles). Icons: Lucide.
Imagery: procedurally generated locker mosaic (our own abstract art, no Epic assets);
real supplier screenshots replace it in production.
